## Tips Memilih Tools Online

Saat menggunakan tools online, perhatikan beberapa hal berikut:

- **Privasi Data** — Hindari mengunggah data sensitif ke tools yang tidak jelas kebijakan privasinya.
- **Pemrosesan** — Tools yang berjalan sepenuhnya di browser cenderung lebih aman karena data tidak dikirim ke server.
- **Batas Penggunaan** — Banyak layanan gratis memiliki batas jumlah permintaan atau ukuran file.
- **Kebutuhan Akun** — Beberapa tools memerlukan registrasi; pertimbangkan apakah itu sepadan untuk penggunaan sekali saja.
- **Kebijakan Penyimpanan** — Periksa apakah file yang diunggah disimpan oleh penyedia layanan.

## Kontribusi

Kami menerima kontribusi dari komunitas untuk menambahkan tools baru. Untuk mengusulkan:

1. Buka issue atau kirim pull request.
2. Sertakan nama tool, URL, dan deskripsi singkat.
3. Pastikan tool tersebut:
   - Memiliki akses publik dan berfungsi.
   - Tidak termasuk spam, phishing, atau malware.
   - Tidak duplikat dengan entry yang sudah ada.
   - Relevan dengan koleksi ini.

Maintainer berhak menolak submission yang tidak sesuai.
